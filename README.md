# Make It Land.

**Built to be chosen, not just seen.**

Website for [Make It Land](https://makeitland.studio), a positioning-led brand and web studio for founder-led businesses. Make It Land is the independent positioning, brand, and web studio of [Nicole Miñoza](https://nicoleminoza.com).

**Live site:** [makeitland.studio](https://makeitland.studio)

## What's here

- `index.html`: home
- `thesis.html`: the studio thesis
- `work/`: case studies
- `writing/`: essays

## Stack

Static HTML and CSS, no build step. Served via GitHub Pages from the `main` branch. Fonts: Fraunces and Hanken Grotesk, self-hosted.

## Working with Make It Land

Make It Land takes on one or two engagements at a time. [Schedule a fit call](https://makeitland.studio) or email hello@makeitland.studio.
